# NOMBRE DEL PROYECTO

El presente repositorio contiene los códigos y referencias principales de nuestro proyecto final del curso IMT3130 "_aplicaciones de ecuaciones diferenciales parciales y análisis funcional en ingeniería_", cursado el primer semestre del año 2026.

El objetivo de este proyecto es adentrarse en el mundo de ecuaciones diferenciales parciales no lineales. En particular, estudiar numéricamente el modelo Keller-Segel. Explícitamente, los objetivos son:


- Derivar el modelo de Keller-Segel.
- Definir una simplificación razonable para el modelo.
- Identificar condiciones para que el problema sea bien puesto.
- Estudiar la discretización del problema y discutir la convergencia y estabilidad de soluciones discretas.
- Resolver la ecuación usando elementos finitos por medio de la librería ```FEniCS``` de ```Python```.
- Estudiar como distintas combinaciones de parámetros entregan variaciones en la formación de patrones estacionarios.
